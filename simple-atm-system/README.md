A clean and beginner-friendly **ATM simulation** built with Python.

Perfect for learning Object-Oriented Programming (OOP), authentication logic, and basic banking operations.

---

### ✨ Features

-  Secure PIN Authentication (3 attempts)
-  Check Account Balance
-  Withdraw Money (with validation)
-  Deposit Money
-  Clean & User-friendly Console Interface
-  Proper Error Handling
-  Zero external dependencies
