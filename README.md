A clean, beginner-friendly **ATM Simulation** built using pure Python and Object-Oriented Programming.

Perfect project for students learning Python, OOP concepts, and building menu-driven applications.

---

### ✨ Features

- Secure PIN Authentication (3 attempts only)
- Check Account Balance
- Withdraw Money (with validation)
- Deposit Money
- Clean and user-friendly console interface
- Proper error handling
- Zero external dependencies
